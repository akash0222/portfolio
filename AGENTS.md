# Project guidance

## Overview
This is a responsive React portfolio for Akash Singh, built with Vite.

## Files
- `index.html` contains document metadata and the Vite mount point.
- `src/App.jsx` contains the portfolio page and navigation state.
- `src/main.jsx` mounts the React app and imports the stylesheet.
- `styles.css` contains the visual system, responsive layouts, and animations.
- `README.md` documents previewing and deployment.

## Working in this repository
- Use `npm run dev` for local development and `npm run build` to verify a production build.
- For interactive changes, verify the relevant behavior in a browser at desktop and mobile widths.
- Preserve semantic HTML, responsive behavior, and accessible labels and states.
- Keep edits focused and follow the existing naming and style conventions.
- Before publishing, confirm external project links and replace the placeholder contact email in `src/App.jsx`.
